1. Create COVID Database Schema
Objective

Create a database and tables to store COVID-19 information.

Step 1: Create Database
CREATE DATABASE covid_db;
Step 2: Use Database
USE covid_db;
Step 3: Create covid_cases Table
CREATE TABLE covid_cases (
    country VARCHAR(50),
    report_date DATE,
    confirmed_cases INT,
    deaths INT,
    recoveries INT,
    population BIGINT
);
Step 4: Create covid_deaths Table
CREATE TABLE covid_deaths (
    country VARCHAR(50),
    report_date DATE,
    deaths INT
);
Step 5: Create covid_vaccines Table
CREATE TABLE covid_vaccines (
    country VARCHAR(50),
    report_date DATE,
    vaccinated_people INT,
    vaccination_rate DECIMAL(5,2)
);

3. Update Case Information
Objective

Update confirmed cases for a specific country and date.

SQL Query
UPDATE covid_cases
SET confirmed_cases = 28200000
WHERE country = 'India'
AND report_date = '2021-06-02';
Verify the Update
SELECT *
FROM covid_cases
WHERE country = 'India';

4. Delete Incorrect Records
Objective

Remove incorrect or duplicate records.

Delete Incorrect Country Name
DELETE FROM covid_cases
WHERE country = 'IN';
Delete Duplicate Record
DELETE FROM covid_cases
WHERE country = 'India'
AND report_date = '2021-06-01'
LIMIT 1;
