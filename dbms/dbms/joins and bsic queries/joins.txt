Use Case 1: Find Highest Confirmed Cases using INNER JOIN
Objective

Retrieve the country with the highest number of confirmed COVID cases on a specific date.

SQL Query
SELECT c.country_name,
       cc.report_date,
       cc.confirmed_cases
FROM covid_cases cc
INNER JOIN countries c
ON cc.country_id = c.country_id
WHERE cc.report_date = '2021-06-01'
ORDER BY cc.confirmed_cases DESC
LIMIT 1;

Use Case 2: Join COVID Deaths and Vaccination Data
Objective

Display death counts and vaccination status for all countries, including those without vaccination records.

SQL Query
SELECT c.country_name,
       d.report_date,
       d.death_count,
       v.vaccination_status
FROM covid_deaths d
LEFT JOIN covid_vaccines v
ON d.country_id = v.country_id
AND d.report_date = v.report_date
INNER JOIN countries c
ON d.country_id = c.country_id;

Use Case 3: Analyze Deaths by Continent
Objective

Calculate the total COVID deaths for each continent.

SQL Query
SELECT ct.continent_name,
       SUM(cc.deaths) AS total_deaths
FROM covid_cases cc
INNER JOIN countries c
ON cc.country_id = c.country_id
INNER JOIN continents ct
ON c.continent_id = ct.continent_id
GROUP BY ct.continent_name
ORDER BY total_deaths DESC;

Use Case 4: Calculate Average New Deaths Per Day
Objective

Find the average number of daily deaths across all countries.

SQL Query
SELECT report_date,
       AVG(death_count) AS average_daily_deaths
FROM covid_deaths
GROUP BY report_date
ORDER BY report_date;

Use Case 5: Find Countries with Highest Infection Rates
Objective

Calculate infection rate and rank countries.

Formula
Infection Rate = (Confirmed Cases / Population) × 100
SQL Query
SELECT c.country_name,
       c.population,
       MAX(cc.confirmed_cases) AS confirmed_cases,
       (MAX(cc.confirmed_cases) * 100.0 / c.population) AS infection_rate
FROM countries c
INNER JOIN covid_cases cc
ON c.country_id = cc.country_id
GROUP BY c.country_name, c.population
ORDER BY infection_rate DESC;
